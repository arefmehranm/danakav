danakav.ir — بستهٔ دموی بدون بک‌اند
====================================

ورود به پنل (کاربر مشتری، هاردکد):
  نام کاربری: demo
  گذرواژه:   danakav

مسیر: صفحهٔ لندینگ → «ورود به پنل» → صفحهٔ مشتری →
داشبورد «تحلیل هوش مصنوعی مصرف برق» (تحلیل تعاملی AI).

استقرار:
1) محتویات همین پوشه را در ریشهٔ وب‌سایت دامنه قرار دهید.
   نکتهٔ مهم: فایل index.html باید در دامنهٔ اصلی سرو شود و
   مسیرها با # (هش روتر) مدیریت می‌شوند؛ پس نیازی به rewrite نیست.
2) یا با Docker:
   docker build -t danakav-demo .
   docker run -d -p 80:80 danakav-demo

برای تغییر نام کاربری/گذرواژه یا کلیدهای سرویس هوش مصنوعی،
فایل danakav-demo.js را ویرایش کنید (بخش DANAKAV_DEMO_CONFIG).
